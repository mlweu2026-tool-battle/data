### Data
Data are based on data set Liar 2 which can be loaded at [https://huggingface.co/datasets/chengxuphd/liar2](https://huggingface.co/datasets/chengxuphd/liar2)
The dataset is described in the paper [An Enhanced Fake News Detection System With Fuzzy Deep Learning](An Enhanced Fake News Detection System With Fuzzy Deep Learning)
